# LG TV native-OS research (65NANO756PR, webOS 6)

Research, evidence, tooling and plans for investigating an internal OS replacement on an owned LG TV. Start with `REPRODUCING.md`, `handoff/` and `evidence/`.

## Excluded inputs
Large or vendor-licensed inputs are **not** committed: LG open-source archives (`source-catalog/archives/`), staged/extracted inspection outputs (`source-catalog/inspection-*/`, `sdk-candidates/**/inspection-*/`), SDK installer/sysroot downloads (`sdk-candidates/**/assets/`), and LG user-guide copies (`official-webos6-guide.zip`, `official-guide-extracted/`, `official-guide-eng.txt`). They are recorded by SHA-256 and download URL in the evidence manifests so they can be re-fetched and verified. No pairing keys, serials or MAC addresses are stored.
