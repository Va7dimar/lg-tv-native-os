## Changed files
1. `src/wayland_hello.c`
   - **Alarm handler:** no longer does any I/O; it calls `_exit(124)` and nothing else.
   - **Proxy checks:** every new object (registry, callback, compositor, shm, shell, surface, shell_surface, shm_pool, buffer) is checked for NULL before it is sent or given a listener.
   - **Listener checks:** every listener install's return value is checked, and listeners now go on before the request that creates the object.
   - **Failure exits:** a failed allocation exits 7 (`EX_ALLOC`) after cleanup; a failed listener install exits 4. `create_buf` now returns an exit code and cleans up the pool/buffer it made if it fails partway.
   - **SHM backing:** `make_shm_file` reserves the file's space with `posix_fallocate` (retrying only if interrupted, within the deadline) and then checks the size with `fstat`. Any error, including an unsupported filesystem, fails closed; there is no `ftruncate` fallback. Buffers are capped at 8 MiB and `INT32_MAX`.
2. `tests/run_tests.py`: the buffer assertions now match `[new_id, offset, width, height, stride, format]` (width `b[2]`, height `b[3]`). They also check offset 0, stride `w*4` and format 1.
3. `scripts/fetch_buster_armel_sysroot.py`: `--allow-unsigned` is gone. The script stops if the keyring or `gpgv` is missing, `gpgv` errors or times out, or the signature is bad. It rejects any argument.
4. `README.md`:
   - Says plainly that nothing has been built, tested or run.
   - The build commands are marked as planned only: no sysroot fetched, no toolchain acquired.
   - States that a power cycle is not a proven restore because the TV boots from a snapshot.
   - States that no run, not even `--dry-run`, is allowed until the documented restore gates are met.
   - Exit codes and SHM/allocation behaviour are updated; the bypass flag is removed.
5. `BUILD-LOG.md`: new session-2 section matching each review finding to its untested change, plus open items. The `--allow-unsigned` advice is replaced with "no bypass".

## Remaining blockers
- **Never built or tested.** There's no sysroot, no ARM cross compiler, and `make test` / `make abi` have never run, so the code may not even compile.
- **New failure paths have no tests.** Nothing exercises the NULL-object, listener-failure or `posix_fallocate`-failure paths; that would need fault injection.
- **`posix_fallocate` on the TV is unknown.** If it doesn't work on the TV's kernel or tmpfs, the surface mode will always exit 7.
- **glibc version unconfirmed.** I expect `posix_fallocate` to stay within glibc 2.28, but `abi-check.sh` hasn't run to confirm it.
- **A misbehaving compositor can still cause a crash.** It holds the shared memory file and could shrink it, which would still crash the client with SIGBUS. This is out of scope and documented.
- **Restore gates not met.** The repo-level restore gates and a proven recovery path are both missing, and a power cycle doesn't count. I didn't read those repo-level documents this session, so the README refers to them in general terms rather than by path.
- **Owner approval.** Separate owner notice is still needed for each TV step.
